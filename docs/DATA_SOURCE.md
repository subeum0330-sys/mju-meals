## 자동 수집 데이터

`backend/collect.py`와 GitHub Actions 워크플로가 구현되어 있으나 **실제 계정·API 키·배포는 아직 연결하지 않았습니다.** 네 식당 계정이 공식 Business Discovery API로 조회 가능한지도 실제 자격 증명으로 확인해야 합니다. 활성화 절차는 [자동 갱신 설정](AUTOMATIC_UPDATES.md)에 있습니다.

활성화하면 공식 Meta API로 최근 게시물 이미지·캡션을 받아 OpenAI API로 판독합니다. 날짜·요일·주차·계정·원문 링크를 검사하고 기존 유효 자료와 병합합니다. 이미지와 캡션이 같으면 기존 판독 결과를 재사용합니다. 정해진 날짜 증거가 부족하거나 판독이 불확실하면 해당 게시물을 등록하지 않습니다.

자동 기록은 `processingMethod: automatic`, `collectedAt`, `sourcePublishedAt`, `sourceDigest`, `temporalBasis`를 보존합니다. `verifiedAt`은 형식 호환용 수집 시각이며 사람이 검수했다는 뜻이 아닙니다. 앱은 **인스타 자동 수집**과 수집 시각을 표시합니다. 형식 검증은 AI 판독의 사실 정확성을 보장하지 않으므로 게시물 원문을 함께 제공합니다.

## 앱의 선택 순서

1. 공개 피드 URL이 설정되어 있으면 피드에서 선택한 식당·주와 일치하는 자료를 찾습니다.
2. 일치하는 원격 자료가 없거나 피드 조회에 실패하면 앱에 포함된 같은 식당·주의 확인본을 찾습니다.
3. 확인본도 없으면 해당 식당·주를 학교 홈페이지에 요청합니다.

어느 단계에서도 다른 주의 메뉴를 재사용하지 않습니다. 피드 오류 후 대체 자료를 보여줄 때는 최신 피드를 확인하지 못했다는 안내를 표시합니다. 학교 홈페이지에도 메뉴가 없으면 그 출처의 미게시로 표시하고 식당 인스타그램 링크를 제공합니다.

현재 공개 피드 주소는 비어 있습니다. 따라서 새로고침만으로 새 인스타그램 게시물이 추가되지는 않습니다. 피드 연결 후에는 앱에서 불러오거나 새로고침할 때 공개 식단을 요청합니다. iPhone의 정시 백그라운드 실행 기능은 아닙니다.
